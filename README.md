# 東專附設高職部｜學生獎懲條文查詢

教師輸入學生行為描述，快速找到對應的獎勵 / 懲處條文。

## 線上使用

啟用 GitHub Pages 後，公告此網址給全校教師即可（免安裝、免登入）。

## 功能

- **關鍵字搜尋**：輸入如「手機」「打架」「抽菸」「霸凌」，自動匹配相關條文（含同義詞擴展、逐字備援檢索）
- **等級篩選**：嘉獎 / 小功 / 大功 / 警告 / 小過 / 大過
- **✨ AI 協助判讀（選用）**：RAG 流程，先本地檢索候選條文，再由 AI 排序解釋；支援 Gemini（免費額度）、Groq、OpenRouter、Grok、Ollama 本地模型
- **隱私保護**：關鍵字搜尋完全離線；AI 模式僅傳送行為描述，並自動偵測提醒去除姓名、班級、座號等個資

## 法規依據（唯一）

- 國立臺東專科學校附設高職部學生獎懲辦法（民國 114 年 12 月 10 日臺教授國字第 1140123471 號函核備通過）
- 共 151 款條文均自官方 PDF 全文逐條謄錄（見 `reference_docs/`）

## 檔案說明

| 檔案 | 說明 |
|------|------|
| `index.html` | 網頁主程式（條文資料已內嵌，單檔即可運作） |
| `reference_docs/ntc_reward_punishment.json` | 結構化條文資料（網頁優先 fetch 此檔，失敗時用內嵌備份） |
| `reference_docs/*.pdf` | 官方辦法 PDF（參照用） |
| `build_official.py` | 由官方條文重建 JSON 的腳本 |
| `embed_data.py` | 把 JSON 內嵌進 `index.html` 的腳本 |

## 法規更新流程

1. 取得新版辦法 PDF，逐條更新 `build_official.py` 內條文
2. 執行 `python build_official.py` 重建 JSON
3. 執行 `python embed_data.py` 重新內嵌
4. commit + push，GitHub Pages 自動更新

## 使用聲明

本工具僅供教師查詢條文參考，最終獎懲裁決依學校獎懲委員會及校長核定為準。
懲處前應給予學生陳述意見機會；不服者得於通知送達次日起 30 日內提起申訴。
